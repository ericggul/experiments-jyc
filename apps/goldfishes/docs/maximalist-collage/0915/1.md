Experimental, 2026-09-15. Route: `/maximalist-collage/0915/1`. Implementation: `components/maximalist-collage/0915/1/`. The user rejected the visual result. This structure correction preserves the trial; it does not resolve that rejection.

## Question and baseline

Can the same hype signal become several incompatible interface utterances, then accumulate as a single flat surface? This trial translates the accumulation/occlusion of `desktop/0915/2` into browser cut-ups; `overlay-4` supplies the conceptual distinction between a propagated attention signal and its changing visual surface. It does not copy the native-window runner or the fish simulation. LinkedIn/3 supplies the precedent of dismantled interface blocks; YouTube/6 supplies dense thumbnail grammar; C-VAL supplies a bounded clipped display rather than a transport dependency.

Mutation: one local click prints a complete stratum of ten fragments. The same topic appears as a video promise, a professional success story, a search query, a generated answer, and notification pressure. The fragments share three 240ms cuts, then freeze. The old print remains under the new fragments. Pictorial depth, window shadows and perspective are absent; source typography is scaled uniformly and then cropped. Large recommended/promoted phrases overprint the interfaces with multiply compositing.

Invariants: existing screen/desktop/SNS/C-VAL implementations and runtime contracts remain independent. No socket, native-app control, autoplaying video, live platform data, AI API, audio, or new dependency. The sampled feed text is authored fiction, not attributed statements by the photographed person. This is a sampled image surface, not functional embedded LinkedIn/YouTube pages.

## Input and record

- Click anywhere, or focus the full-stage button and press Enter/Space: add one stratum. Two fragments anchor around that point; others spread across the field. A second click during a cut commits the previous visible state immediately; it does not grow a waiting queue.
- Pause cuts / Escape: hold the current cut. Clicking still prints a static layer. Resume allows the remaining cuts. Reduced-motion preference suppresses recutting; hidden tabs stop the timer.
- Save image: download the full 1600 × 1000 PNG. The display uses proportional cover cropping, so narrow viewports show a subset, not squashed text. The saved image includes the complete composition.
- About → Save click record: JSON with IDs, coordinates and last cut phase for the most recent 2,048 events. No reload persistence. The record is not a complete event history after that bound; the accumulated raster still retains earlier visible marks. No replay/import UI is implemented.

There are two persistent 1600 × 1000 canvases (about 12.8 MB of raw RGBA storage), a single current stratum, at most one timeout, two decoded image assets, and short-lived fragment canvases. This is an architectural bound, not a measured GPU or FPS claim. Nothing runs continuously when the latest cut has settled. The composition is rasterized; individual buried fragments cannot be selected or recovered from the PNG.

## Proposed later connection — pseudocode only

```text
on existing attention / propagation event:
    assign a stable event ID and domain topic
    derive the collage input position locally
    map domain topic to a local sample vocabulary
    create and print one stratum

multiple displays, if requested later:
    transport domain event ID + topic + server timestamp only
    each browser derives its layout and cut phase
```

The current model deliberately sequences eight topics from click IDs; it does not yet accept real network topics. The attention loop in overlay-4 (including its tuned transmission probability) is an artistic model, not a measured dopamine mechanism. Mobile input, propagation and collage output are separable relations. “Synchronized” currently means the fragment voices share one local cut clock; no multi-device synchronization exists.
