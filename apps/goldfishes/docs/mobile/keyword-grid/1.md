# Goldfishes mobile/keyword-grid/1

Route: `/mobile/keyword-grid/1` · 2026-09-30

Short description: **Square dot map · configure a keyword, place it on a point, finger-skate to keep it alive.**

```text
question: can the bare attention grid become a phone surface where keywords survive only through touch?
baseline: /screen/2d/1 grid spacing (primary scale 2); SCC finger-skating/field/1 pointer discipline
mutation: goldfish, media and Leva removed; a 1:1 dot map shows a crop of an unbounded point landscape; keywords are configured first, then placed; bubbles decay and grow under finger contact
invariants: 2d/1 cell rule (clamp(round(side/30), 20, 30) × 2)
evidence: placed bubbles shrink away unless a finger rests or skates over them
```

## Flow

1. The map is a centred square window of grid dots. World point (0, 0) sits at its centre; dots continue to the window edge, so the window reads as a crop of a larger landscape. It does not pan yet. Touching the map never creates anything by itself.
2. A large `+` sits below the map. It opens a glossy modal (translucent fill, 28px backdrop blur, specular top edge) with name, size (base diameter in cells, 0.5–3) and weight (white fill opacity). Touching outside the modal closes it without creating anything.
3. `place on map` closes the modal and replaces the `+` with `tap a point on the map`; the grid dots brighten from 50% to full white.
4. The next touch on the map snaps to the nearest point at least 8px inside the window and creates the bubble at that moment, on touch-down. The `+` returns.

## Bubbles

- Target scale starts at 1 and falls by 1/8 per second (gone after 8s untouched). While a finger rests or skates over a bubble, the scale rises by 8 per second instead (a ~60ms skate pass adds about 0.5), up to 2.5. The drawn scale eases toward the target (`1 − e^(−24·dt)`); outline and fill fade out below a quarter of base size. Diameter is `size × cell × shown scale`; the name is drawn beside it.
- Contact follows the finger-skating pointer rules: pointer capture, coalesced samples, several simultaneous pointers, no lift needed between bubbles. Each frame tests the entire path travelled since the previous frame against every bubble, with a finger reach of `max(22px, radius + 12px)`.

## Implementation

- No scrolling: the page is fixed, `touch-action: none` covers the whole interface, and document overflow and overscroll are disabled while mounted.
- One opaque Canvas2D loop draws the map; it runs only while bubbles or pointers exist. The dot grid is rasterised once per size into two cached layers (normal and placing) and blitted each frame. DPR is capped at 2.
- The modal's backdrop blur is applied only while it is open. The modal rises above the software keyboard via `visualViewport`.
- State is local to the page session.

## Visual register

Black and white, following portfolio-v4 `/oi` (`#000`, Menlo 13px/1.35, `#ddd`/`#999`); the modal is the one glossy material surface, with a white pill button.

## Open

- The keyword role of name and weight is reserved for a later experiment; weight only changes fill opacity.
- Rates (8s decay, 8/s growth, 2.5× cap) are unobserved first guesses.
- Earlier builds were reported as janky on the user's device; the cause was not identified by static inspection. Frame timing on a phone remains unmeasured.
