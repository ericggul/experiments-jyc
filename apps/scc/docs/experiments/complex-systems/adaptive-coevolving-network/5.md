# Route 5: self-organized critical threshold network

Route `/adaptive-coevolving-network/5`, 2026-10-02. Component: `components/complex-systems/adaptive-coevolving-network/5/` (`ThresholdNetworkFive`).

## Model card

- **Object and boundary.** A deliberately synthetic mathematical demonstrator: a finite random threshold network (Boolean "neurons" with signed inputs) whose wiring is changed by a local rule that reads only each node's own recent activity. It makes no claim about real brains or gene networks.
- **State.** 120 nodes with `σ_i ∈ {−1, +1}`. Directed links `j → i` with weight `w_ij ∈ {−1, +1}` (absent links are `0`), no self-links, at most one link per ordered pair. `K` is the mean number of inputs per node.
- **Dynamics (every update, all nodes in parallel):** `σ_i(t+1) = sgn(Σ_j w_ij σ_j(t) + h)`, with `h = 0` and `sgn(0) = +1`, as in the paper.
- **Topology rule (after every update, `r = 2` times):** pick a random node `i`. If `σ_i` has not changed in the last `W = 16` updates (frozen), add an input `j → i` from a random non-input `j` with a random sign. Otherwise (active), delete one of its inputs at random. The rule is skipped for the first `W` updates.
- **Defaults.** `N = 120`, initial `K = 1` (Poisson in-degrees), `h = 0`, `W = 16`, `r = 2`, seed `0x3c6ef372`.
- **Macro observable.** `K` and the share of active nodes. **Intervention:** flipping a node (perturbation) and imposing a `K`. **Contrast:** sparse and dense starts converge to the same `K` band, and the same flip dies out, spreads moderately, or floods the network depending on `K`.

### Deviation from the source

Bornholdt and Rohlf restart each epoch from a random state, run the dynamics to its attractor (or a cap), judge the chosen node on the attractor, and change one link per epoch. That cannot be shown at a readable blink rate, and it would hide the trajectory that the rule reads. Here the trajectory never restarts, "frozen" means "unchanged during the last `W` updates", and two nodes are judged after every update. The rule's own link changes, and the participant's flips, take over the role of the random restarts as perturbations. Prototype comparison at `N = 128` (scratch, seed 7, 6000 epochs vs 20 000 updates): the paper's epoch rule settled at `K ≈ 3.3 ± 0.4`; the continuous rule at `K ≈ 3.1 ± 0.3` (W = 16). Both balance where a randomly chosen node is frozen half the time.

Nothing runs off-screen: the displayed blinking is the model's trajectory, at 8 parallel updates per second (3 with reduced motion), so `W` is 2 s.

## Screen

- White field. A node that is **on** is a filled disc, **off** an open ring. **Red** while it has changed within the last `W` updates (active), **ink** while it has stayed still (frozen). Disc size grows with the number of inputs.
- Links run from source to target. Excitatory links end in an arrow, inhibitory ones in a bar, just short of the target. Links from frozen sources are faint ink; links from active sources are red, because only they can pass change on.
- **Link events** (fade in 0.9 s): a frozen node gaining an input draws the new link out toward it in ink; an active node losing one leaves a dashed red trace. The colour of the event is the colour of the node it acts on, which is the rule.
- **Damage:** after a flip, the unflipped trajectory keeps running as a twin in the model. Any node whose state differs from the twin carries a second red ring. The twin is dropped once the two trajectories agree, or after 40 updates (5 s).
- Layout is a browser-only force layout of the current links (direction ignored); it never feeds back into the model.
- No title, counters or legend. The share of active nodes, `K`, and the current damage size are exposed only to screen readers, every 2 s.

## Interaction

- **Tap a node** (within its radius + 10 px) to flip it. Its ring and the damage rings show how far the flip travels. **Enter/Space** on the focused canvas flips the node nearest the centre.
- **옵션/닫기** toggle at the bottom centre (route 2 grammar). Open, it shows a short Korean description, the views, and a **성김–빽빽함** slider (`K ∈ [0.25, 6]`).
- The slider is live. When no one is holding it, the thumb follows the network's own `K` every 0.4 s. Moving it adds or removes uniformly random links at once until `K` matches, and the topology rule then pulls `K` back. This is the one quantitative display, and it is kept because "set it, watch it return" is the claim; there is no number.
- **Views** (eased 0.9 s cubic in-out from the current points, then followed at rate 12/s):
  - *네트워크:* the force layout.
  - *입력 수:* one column per number of inputs (0 to 10+), stacked upward, frozen nodes below active ones. The columns are a histogram of in-degree whose centre of mass is `K`, and they show that frozen nodes sit in low columns and active ones higher up.
  - *멈춤·깜빡임:* two discs whose areas follow the frozen and active shares; each node keeps a fixed sunflower spot by id. The rule stops moving `K` only when the two discs are about equal.
- A one-line hint above the toggle (`점을 누르면 켜짐과 꺼짐이 뒤바뀜`) stays until the first flip.
- Threshold `h` is **not** a control. Pure-model runs at `N = 128` evolved `K ≈ 3.1` for `h ∈ {−1, 0}` but `K ≈ 12–21` for `|h|` one step larger. At the larger values `K` was still rising after 8000 updates (17 min of screen time) and the screen would need thousands of links.

- Both starts reach the `K ≈ 2.4–3` band within about 240 updates (30 s on screen) and then fluctuate around 2.6–3.2. The paper reports `K → 2` only as `N → ∞`, with finite networks settling higher (`K_ev(N) − 2` falls as a power of `N`). The paper-faithful prototype gave `K ≈ 4.2` at `N = 64` and `3.4` at `N = 128`, consistent with that.
- **Damage, fixed topology** (rule off, seed 5, peak number of nodes differing from the twin within 30 updates, 200 flips): `K = 0.5` mean .4 (190 of 200 ≤ 1); `K = 2` mean 1.6, max 8; `K = 3` mean 4.9, median 2, 90th percentile 20, max 34; `K = 6` mean 43.9, median 56.
- **Damage on evolved networks** (3000 updates, then fixed, 240 flips): seed `0x3c6ef372` (K 2.78): 130 ≤ 1, 47 at 2–3, 49 at 4–7, 14 at 8–15. Seed 7 (K 2.74): 104 ≤ 1 but 78 above 32. Seed 99 (K 2.75): 129 ≤ 1, 57 at 4–7, 18 at 8–15. The evolved network sits between "dies at once" and "floods". At this size the distribution is broad but differs strongly from network to network.

## Cost

Node, 390 × 644 field, 3000 frames: model updates (8/s), activity flags, layout relaxation and view targets took about .022 ms per frame on average (p99 .06 ms, worst 1 ms) at the evolved `K`, and .027 ms at an imposed `K = 6`. A single parallel update costs about .005 ms. Canvas drawing has not been profiled in a browser.

## Tests

`model.test.ts`: deterministic replay; every node follows the signed input sum; only frozen nodes gain and only active nodes lose inputs; sparse (0.5) and dense (5) starts converge into `2 < K < 4` within 0.8 of each other (two seeds); with the rule off, `K` stays fixed; the evolved network keeps 40–60% of nodes active; a flip dies out at `K = .5` (mean peak < 1.5) and floods at `K = 6` (> 25); the damage twin closes; imposing `K` hits its link count and keeps links simple. `views.test.ts`: the 멈춤·깜빡임 view never mixes groups (wide and tall frames); every view stays in frame at `K` .25, 1 and 6; the 입력 수 view orders columns by input count.

## Unresolved

- Whether 120 nodes are enough for the participant to see "broad" avalanches as opposed to merely "medium" ones. The evolved damage distribution varies strongly between seeds.
- Whether the 2 s window reads as "frozen" to a viewer of a periodic attractor of period > 16, where a node blinks too slowly to count as active.
- An attractor-based variant (the paper's restarts), shown as visible resets, was not tried.
