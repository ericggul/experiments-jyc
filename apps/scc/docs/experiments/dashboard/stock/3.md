The arrays in `model/workstation-data.ts` own stable IDs.

At >1200px the mosaic is `100dvh` without scrolling. At 721–1200px panels become paired columns; below 720px they are single column; below 431px tiles become 2×10 and macro cards 2×4. The matrix retains a 900px inspectable width on narrow screens. Never hide or clip records; recalculate panel heights when counts change.

## Interaction and visual invariants

One `symbol` state is updated by command input, return tiles, sovereign and active rows, matrix rows, and macro cards; it feeds the security label and relative chart. Use accessible overlays for macro cards without nesting flow landmarks inside a button.

Use compact tabular monospace (`clamp(10px, min(0.7vw, 1.18vh), 14px)` base), right-aligned numbers, terminal rules, orange functional labels, green/red direction, cyan selection, purple comparison. No rounded cards, glow, gradients, faux-live badges, or ornamental metrics. Charts use seeded cumulative drift/noise/impulses—not `Math.random()` or sine waves—to keep hydration and screenshots stable.
