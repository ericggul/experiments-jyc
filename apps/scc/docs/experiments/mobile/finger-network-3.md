# Mobile finger-network/3

- **Route:** `/mobile/finger-network/3`
- **Date:** 2026-10-02
- **Baseline:** [`/mobile/finger-network/1`](finger-network.md): black field, every pair of nodes joined by one white edge, node dot, fixed ring, and expanding pulse ring, 1.5 DPR cap. `/1` remains independently addressable.

The changed relation is node lifetime. In `/1` a node exists only while its finger touches the screen. Here every new contact adds a node, and the node follows its finger while held. When the finger lifts or the touch is cancelled, the node stays where it was left and fades linearly to nothing over 5 s, then is removed. (The first fading version used 10 s. A same-day trial that set each lifetime between 5 and 20 s by edge count, with the ring radius showing remaining life, was judged worse and reverted.) Later touches add new nodes, so the network accumulates only as long as touches keep arriving. (Earlier on 2026-10-02 left nodes stayed indefinitely.) A reused touch identifier always starts a new node and never moves an earlier one.

Edges follow touch sessions. A session runs from the first finger down on an empty screen until the last finger lifts; a finger added while others are still down joins the current session. Nodes of the same session form a complete graph (three fingers give `K₃`), whether they are held or already left. Nodes of different sessions are joined only within a reach of 0.3 × the screen's shorter side (about 117 px on a 390 px-wide phone), measured live, so dragging a held node toward older ones links and unlinks them. (The first 2026-10-02 version joined every node to every other.)

Held nodes keep `/1`'s expanding pulse ring; left nodes keep only the dot and fixed ring, which marks which ones are currently moving. A node's dot and ring dim with its remaining life, and each edge is as bright as its weaker end, so a session's graph fades with its nodes and a held node's links to older nodes dim as those nodes do. Edges, node rings, dots, and people are batched by opacity into 24 steps, and all pulse rings share one path, so stroke calls per frame stay bounded however many nodes and people exist. The canvas redraws every frame while any node exists and stops once the last one has faded; the instruction text returns then. `/1`'s `?touch-debug` overlay is not carried over.

## People option (2026-10-02)

An option at the bottom of the screen raises a person from each touch session. It was first tried as a separate `/4` route the same day and then merged here; `/4` no longer exists. A small `옵션` button opens a `사람 꺼짐/켜짐` toggle above it, and `닫기` collapses it again. People are off by default, so the unopened route behaves as before. The controls use the instruction text's typography, the instruction moves up to clear them, and touches that start on the controls do not create nodes.

With people on, each session's nodes carry one stick figure (head circle, spine, two-segment arms and legs) built on a standalone copy of [`/2`](finger-network-2.md)'s rig and read by `/2`'s rules: two nodes are head and feet, three are head and both feet, four are hands and feet, and five are the full body. A session with more than five nodes uses its newest five, and a replaced node rereads the hand, which the body eases into over 0.6 s. A single-node session raises no one. A person's opacity is that of its session's most alive node, so it fades with its network; as earlier nodes are removed, the parts they held freeze in place (`/2`'s frozen-pose rule), so the shape holds until it is gone. Once a session has a person, that session's network recedes: its edges, node rings, dots, and pulse rings draw at 0.2 × their usual opacity, while the person draws at full opacity (still fading with the session). An edge between sessions takes the fainter of its two ends. Sessions without a person, such as single-node ones, keep the normal network. Turning the option off drops all people at once and restores the full network.

The `/4` trial first drew `/2`'s shaded, textured, shadow-blurred body per person. It was replaced by the stick figure so that many people stay cheap: people at one opacity are one path and one stroke. In a headless count with the option on, 20 people and their nodes drew in 28 stroke calls per frame, against about 88 before batching.

The pure model test covers left nodes staying in place, accumulation over later touches, cancellation keeping nodes, stable node IDs across reused touch identifiers, session membership for fingers added mid-session, the same-session and reach rules, linear fading and removal of left nodes while held nodes stay alive, a person appearing from session nodes and keeping its shape as anchor nodes disappear, and no person from a single node. Every frame checks all `n(n − 1)/2` pairs with no node cap; frame cost, whether the 0.3 reach reads well, and the control placement are unmeasured on device.
