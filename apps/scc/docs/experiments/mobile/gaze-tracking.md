# Gaze tracking — /mobile/gaze-tracking

2026-09-24. A mobile-first example in which two dots move on the interface according to the left and right iris positions. The front camera's video is processed locally by [MediaPipe Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker/web_js) and is not shown or stored. The user explicitly starts camera access; leaving the page or hiding the tab stops the tracks. It also works with a desktop webcam.

The task returns 478 face landmarks, including iris centres. Each iris is measured relative to its own eye corners and eyelids, so head translation has less effect than mapping raw camera coordinates. The horizontal camera image is reversed into the viewer's direction. A centre calibration samples both eyes while the participant looks at the centre; the dot motion is smoothed and inference is capped at about ten frames per second to limit mobile main-thread work. The task's `.task` model comes from the [official model bundle](https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/latest/face_landmarker.task) (SHA-256 `64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff`). SIMD/non-SIMD Wasm files are copied from the installed `@mediapipe/tasks-vision` 1.0.1 package. These files are served from this app so the runtime does not depend on a third-party CDN.

The dot renderer interpolates toward each new gaze target on every animation frame. Its time-based damping smooths the visible movement between the slower camera estimates without changing detection or the projected gaze coordinates.

These dots show **relative eye direction**, not a measured screen fixation point. A single front camera and one centre sample cannot recover an accurate per-person screen coordinate; head rotation, glasses, eyelid occlusion, lighting and camera placement can all shift the estimate. No iOS or Android device runtime check was authorized in this turn, so device compatibility and perceptual accuracy still require device testing.
