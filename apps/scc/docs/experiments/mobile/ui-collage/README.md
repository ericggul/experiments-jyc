# Mobile ui-collage

Everyday interface components (loaders, progress bars, sliders) are cloned faithfully from many platforms and eras, then tiled across the phone screen so that finger skating plays them as one surface. The family began as `mobile/loading` on 2026-10-03 and was renamed before its first commit, once sliders made "loading" too narrow. Each route is independent; none imports another. volume/1 imports only parametric-interface's song data.

- [loading/1](loading-1.md): a centred grid of twelve circular phone loaders that fill by themselves; skating restarts each one it crosses. `/mobile/ui-collage/loading/1`.
- [loading/2](loading-2.md): full-width horizontal progress bars in eighteen historic styles from MS-DOS Setup to Material 3, stacked in rows; skating sets each bar it crosses to the crossing position (mid-screen is 50%), and the bar glides there. `/mobile/ui-collage/loading/2`.
- [loading/3](loading-3.md): semantic substitution of loading/2. Each bar is the word `LOADING` repeated (×10 by default) in a randomly drawn face from a category-balanced pool, or a random language in 다국어. It is fitted to the bar, dim (0.1) where unfilled and full ink where filled. Same loads, gliding seeks. `/mobile/ui-collage/loading/3`.
- [sliders/1](sliders-1.md): narrow vertical sliders in historic-to-current designs; skating sets each slider it crosses to the finger's height, like drawing on a graphic equaliser, and sounds each slider's pentatonic note (low at the bottom, high at the top). `/mobile/ui-collage/sliders/1`.
- [sliders/2](sliders-2.md): semantic substitution of sliders/1 in loading/3's grammar. Each slider is the word `SLIDER` repeated and turned on its side, in a random face (or a random language in 다국어). It is always all black and always holds every word; the value a finger skates in stretches the line from the bottom edge, from scaleY(0) to scaleY(1). It has the same pentatonic sound. `/mobile/ui-collage/sliders/2`.
- [volume/1](volume-1.md): sliders/2's stretched columns as an mp3 spectrum visualiser for U2's *You're the Best Thing About Me* (parametric-interface's song data). Every column shows the word being sung, each in its own face, and all change at once with the next word. Each is stretched up by the loudness of its frequency band. `/mobile/ui-collage/volume/1`.
