# LinkedIn 3

Experimental local fork at `/sns/linkedin/3`, created 2026-09-13 from the
complete `/sns/linkedin/2` reconstruction. The interaction model, local
content, assets, and view-state transitions are preserved as the baseline.

The tested relation is a superflat maximalist digital-interface collage:
LinkedIn's profile, search, navigation, composer, feed cards, action rows,
puzzles, recommendations, and messaging dock become freely placed canvas
modules. The `/2` appearance and starting desktop coordinates remain intact;
only spatial hierarchy can change through direct manipulation.

Dragging a non-interactive module surface moves its layout and brings it
forward. With the default nested-layer mode, interior containers gain a
separate relative offset: moving a parent carries its children, while moving a
child changes only that child’s offset inside the parent. Buttons, links,
inputs and media retain their local interaction; wheel, trackpad and touch
gestures remain scrolling. The English control panel exposes opaque/transparent
surfaces and parent/nested layer modes. It has not been assessed as a usability
replacement for the baseline.
