# LinkedIn 4

Experimental local reconstruction at `/sns/linkedin/4`, created 2026-09-13. This is an independent copy of `/2`; `/1`, `/2`, and `/3` remain unchanged.

The display boundary starts at `+1`: printable ASCII advances by its literal code point, including letters, digits, spaces, and punctuation (`a → b`, `z → {`, `. → /`, and space → `!`). Complete Hangul syllables move by the same amount and wrap inside `U+AC00`–`U+D7A3`, so Korean remains valid Hangul rather than breaking into unrelated characters. Other non-ASCII characters, including emoji, remain unchanged. Source code, paths, keys, URLs, and interaction state remain intact. The boundary applies to text nodes and user-facing text attributes when the interface first renders and when interactions add or update UI.

A right-hand experimental control panel begins expanded, using the lower-case English field/panel grammar of Goldfishes `overlay-4`: `text`, `type`, and `image`. `shift` controls the text/Hangul offset from `-8` to `+8`; `roman numerals` renders supported display numbers (0–3999, including grouped values) as Roman numerals and leaves their Roman symbols literal. `size` changes only computed font sizes (`25%`–`1000%`) while retaining each element’s original line-height and leaving all grid dimensions, widths, gaps, and control geometry untouched. `system`, `roman`, and `times new roman` switch the display typeface without changing layout geometry. `egyptian glyphs` replaces non-whitespace display characters with a deterministic Egyptian-hieroglyph sequence while retaining word spacing and line breaks. `hue` applies `hue-rotate()` to local and remote photographic images, beginning at `+20°` and ranging from `-180°` to `+180°`; `black monochrome` adds a restrained dark desaturation. Interface glyph assets retain their native color. The panel is excluded from the text transform so its controls remain legible.
