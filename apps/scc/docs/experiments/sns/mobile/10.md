# COMMON — /sns/mobile/10

Experimental London neighbourhood marketplace, 2026-09-23. Independent entry,
model, screen and CSS module; `/sns/mobile/5` supplied the behavioural baseline
only. Fresh visual composition and native UK copy replace that route’s styling.

The participant browses nearby second-hand items, checks collection details and
starts a local conversation. A compact header, prominent For sale & free heading,
category shortcuts, free/filter/sort controls and dense two-column photography
follow the operational grammar of the inspected official Nextdoor mobile image.
Green marks actions and selection; listing photos carry the content, not a hero.
GBP, collection language and Hackney / Dalston / Stoke Newington localities are
fictional adaptations rather than a claimed current Nextdoor replica.

Eight seed listings; search, area/category/free filters, recent/near/price sort,
saved listings, details, validated offers, conversation inbox and message composer
work with session state. Photo-backed listing creation accepts JPEG/PNG/WebP up
to 2 MB and validates title, description and GBP price. Own listings support
Available / Reserved / Sold. Empty states have relevant recovery actions. Native
dialogs, stable IDs, safe-area navigation and a 480px container support mobile use.
All listings, photos and messages remain local to this visit. No real seller,
publication, payment, geolocation or simulated reply is involved. Disclosure
appears where a listing or message is created. Existing image URLs are reused;
remote image availability remains a runtime dependency.
