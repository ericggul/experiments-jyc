# REP — `/sns/mobile/9`

Independent English-language NYC fitness-booking study, added 2026-09-23. The primary action is finding a timed class, comparing its credit cost, and reserving it. Routes 1–8 remain separate.

Visual source: [official ClassPass landing page](https://classpass.com/try/los-angeles), specifically its [historical mobile schedule screenshot](https://images.ctfassets.net/ew96z4wsnz93/2vKqZHRAUQWeOksGiyMo4A/03611e0b57ab87742d8a18ce78b41c5e/credits.jpg), inspected before implementation. The reference has a compact top search/date region, narrow left time column, central class/studio hierarchy, and right-aligned credit count. REP adapts that operational grammar into a fictional service; it does not claim to reproduce the current ClassPass app. Device chrome and decorative row separators are omitted.

Schedule: 98 sample sessions across September 23–October 6, 2026, four fictional studios, Eastern time. Date buttons, bounded previous/next week, native date picker, text search, activity, neighborhood, and time filters work together. Saved studios return to their filtered schedules. Class details include preparation instructions and reservation review. The account begins with 30 demo credits. A pure reducer rejects duplicates, overlapping reservations, and insufficient credits; cancellation restores a reservation's credits only once. All state is page-session-only. No real reservation, payment, location permission, or communication occurs.

Studio-detail imagery uses remote Unsplash exercise photographs with descriptive alt text; these are illustrative, not photographs of the fictional businesses. Cycling detail omits photography rather than substituting unrelated training equipment.

The implementation is contained at 320–480px with safe-area padding and native modal dialogs. Model and CSS are local to this variant. Static validation is handled with the parent integration; no browser or runtime verification was authorized, so rendered fidelity and remote image availability remain unverified.
