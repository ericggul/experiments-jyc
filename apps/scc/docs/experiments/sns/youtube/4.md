# SNS YouTube 4

Route: `/sns/youtube/4`

## Three-fold inverse squeeze — 2026-08-27

- **Baseline:** `/sns/youtube/3`, retained unchanged.
- **Changed variable:** three independent, unchanged `/sns/youtube/2` surfaces
  replace the single surface. On desktop, three phone layouts occupy stacked
  horizontal bands; on mobile, three desktop layouts occupy side-by-side vertical
  strips. The repeated direction is compressed by an additional factor of three.
- **Invariant:** the source interface, its data, controls, and responsive
  breakpoints remain those of YouTube 2. YouTube 3 is not changed.
- **Participant situation:** the inverted scale is no longer a single awkward
  device, but a tiled field of its own mismatched interface.
- **Perceptual job:** make the original horizontal desktop/vertical phone
  reading directions recur as a dense opposing field without added interface
  chrome.
- **Interaction job:** each tile remains an independent live instance of the
  original local interface.
