# SNS YouTube 5

Route: `/sns/youtube/5`

## Parametric normal-scale columns — 2026-08-27

- **Baseline:** the responsive source rule from `/sns/youtube/2`.
- **Changed variable:** the source now matches the enclosing device: desktop
  interface on desktop, phone interface on mobile. The `columnCount` parameter
  in `screen.tsx` determines how many independent copies divide the viewport;
  each copy occupies `1 / columnCount × 1` and is compressed only horizontally.
- **Invariant:** the source interface, its data, controls, and responsive
  breakpoints remain those of YouTube 2. YouTube 3 and YouTube 4 are unchanged.
- **Participant situation:** a familiar native-scale interface becomes a
  parametric column field rather than an inverse-device surface.
- **Perceptual job:** hold vertical reading height constant while repeating the
  complete interface across adjustable narrow horizontal domains.
- **Interaction job:** each column remains an independent live instance of the
  original local interface. The foreground column collection implements the
  repository's finger-skating contract: pointer-down begins a captured
  continuous gesture, `elementFromPoint()` resolves the column at every current
  position (including coalesced samples), and the vertical finger delta is
  relayed to that same-origin column's real internal document scroll. The
  column motions are batched in `requestAnimationFrame`, retain independent
  target positions and velocities, and decelerate after release rather than
  jumping at each input event. Skating across columns therefore scrolls each
  encountered interface independently; pointer-up, cancel, or lost capture
  ends the gesture. Keyboard activation scrolls its focused column, while hover
  alone does nothing.
